# Task 4 -- Sales Prediction using Python

📌 Project Overview

This project performs Sales Prediction using Python and Machine Learning. The main objective is to predict product sales based on advertising expenditure through different media channels such as TV, Radio, and Newspaper.

🎯 Objectives

Predict sales using advertising expenditure.

Analyze the relationship between advertising and sales.

Perform data cleaning and preprocessing.

Perform Exploratory Data Analysis (EDA).

Create meaningful visualizations.

Train a Linear Regression model.

Evaluate the model performance.

Predict sales for new advertising data.

🛠️ Technologies Used

Python

Pandas

NumPy

Matplotlib

Seaborn

Scikit-learn

Jupyter Notebook / VS Code

📂 Dataset

The dataset contains advertising expenditure and sales information.

Main columns:

- TV
- Radio
- Newspaper
- Sales

🔄 Project Workflow

Import the required Python libraries.

Load the advertising dataset.

Inspect the dataset.

Check missing and duplicate values.

Clean the dataset.

Perform statistical analysis.

Perform Exploratory Data Analysis.

Create visualizations.

Select input features and target variable.

Split the dataset into training and testing data.

Train a Linear Regression model.

Generate predictions.

Evaluate the model.

Predict sales for new advertising expenditure.

📊 Analysis and Visualizations

The project includes:

- Sales distribution plot.
- TV advertising vs Sales scatter plot.
- Radio advertising vs Sales scatter plot.
- Correlation heatmap.
- Actual vs Predicted Sales plot.

📈 Key Insights

The analysis helps identify:

- The relationship between advertising expenditure and sales.
- The advertising channel that has a stronger relationship with sales.
- The overall distribution of sales.
- The accuracy of the prediction model.
- The difference between actual and predicted sales.

🤖 Machine Learning Model

Linear Regression is used for Sales Prediction.

Input Features:

- TV
- Radio
- Newspaper

Target:

- Sales

Model evaluation is performed using:

- MAE
- MSE
- RMSE
- R² Score

Sales Prediction using Python demonstrates how machine learning can be used to predict sales from advertising expenditure. Linear Regression provides a simple and effective approach for understanding the relationship between advertising investments and sales.
