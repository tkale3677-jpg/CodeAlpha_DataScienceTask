# 🌸 Task 1: Iris Flower Classification

## 📌 Project Overview

Iris Flower Classification is a Machine Learning classification project that predicts the species of an Iris flower based on its physical measurements.

The project uses the famous **Iris dataset** provided by Scikit-learn. The model classifies Iris flowers into three different species:

- Setosa
- Versicolor
- Virginica

The prediction is based on four features:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

---

## 🎯 Objectives

The main objectives of this project are:

1. To understand the basics of Machine Learning classification.
2. To load and explore the Iris dataset.
3. To perform basic data preprocessing.
4. To visualize relationships between flower features.
5. To divide the dataset into training and testing sets.
6. To train a Logistic Regression classification model.
7. To evaluate the model performance.
8. To predict the species of a new Iris flower.

---

## 📊 Dataset

The Iris dataset contains **150 observations** and **4 input features**.

### Features

| Feature | Description |
|---|---|
| Sepal Length | Length of the sepal in cm |
| Sepal Width | Width of the sepal in cm |
| Petal Length | Length of the petal in cm |
| Petal Width | Width of the petal in cm |

### Target Classes

| Class | Species |
|---|---|
| 0 | Setosa |
| 1 | Versicolor |
| 2 | Virginica |

## 🤖 Machine Learning Algorithm

### Logistic Regression

Logistic Regression is a supervised Machine Learning algorithm commonly used for classification problems.

In this project, Logistic Regression is used to classify an Iris flower into one of the three species based on its measurements.
