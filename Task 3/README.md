# Task 3 -- Car Price Prediction

📌 Project Overview

This project performs Car Price Prediction using Python and Machine Learning. The analysis uses a dataset containing information about used cars. The project focuses on understanding the factors that affect car prices and building a machine learning model to predict the selling price of a car.

🎯 Objectives

Predict car selling prices using Python and Machine Learning.

Understand the factors affecting car prices.

Analyze the relationship between different car features and selling price.

Perform data cleaning and preprocessing.

Perform Exploratory Data Analysis (EDA).

Create clear visualizations to understand the dataset.

Train a machine learning regression model.

Evaluate the performance of the prediction model.

Generate predictions for car selling prices.

🛠️ Technologies Used

Python

Pandas

Scikit-learn

Jupyter Notebook / VS Code

📂 Dataset

The dataset contains used-car information such as:

- Car Name
- Year
- Present Price
- Selling Price
- Kilometers Driven
- Fuel Type
- Seller Type
- Transmission
- Owner

Note: The exact column names may vary depending on the dataset used.

🔄 Project Workflow

Import the required Python libraries.

Load the car price dataset.

Inspect the dataset.

Check missing and duplicate values.

Clean and preprocess the data.

Perform exploratory data analysis (EDA).

Analyze the relationship between car features and selling price.

Encode categorical variables.

Select relevant features.

Split the dataset into training and testing data.

Train the machine learning model.

Predict car selling prices.

Evaluate the model performance.

Interpret the results and prepare conclusions.

📊 Analysis and Visualizations

The project includes:

- Distribution of car selling prices.
- Present Price vs Selling Price scatter plot.
- Year vs Selling Price scatter plot.
- Correlation heatmap.
- Actual vs Predicted Selling Price graph.
- Other visualizations required for meaningful analysis.

📈 Key Insights

The analysis helps identify:

- Factors that influence car selling prices.
- Relationship between present price and selling price.
- Effect of car year on selling price.
- Effect of kilometers driven on car value.
- Differences in prices based on fuel type, seller type, and transmission.
- Accuracy of the machine learning prediction model.

🤖 Machine Learning Model

A Random Forest Regression model is used to predict the selling price of cars.

The dataset is divided into training and testing sets. The model learns patterns from the training data and predicts selling prices for the testing data.

The model performance is evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

Car Price Prediction demonstrates how Python and Machine Learning can be used to analyze used-car data and predict selling prices. The project includes data cleaning, exploratory data analysis, visualization, feature preprocessing, model training, prediction, and evaluation.
